# V Notice — Archive

This directory contains historical test verifications, visual audit captures, and legacy backup files that are preserved for auditability and history, but are not active runtime components.

---

## Directory Contents

### 1. `archive/legacy/`
- **`notices.backup.json`**: Historical JSON backup of early notices data from pre-SQLite phases.
- **`brand_old_backup/`**: Pre-v2.2 brand assets, icon drafts, and logo test cuts prior to the Document Sheet Monogram unification.

### 2. `archive/verification/`
- **`verification_mobile_perf/`**: Visual audit screenshots of mobile performance verification at 390w (notices list, new notice modal, screens tab, display header).
- **`verification_text_fit/`**: Dynamic text auto-fit before/after comparison screenshots at 1920×1080 and 800×480 resolutions.
- **`verification_voice_polish/`**: Voice notice announcement test screenshots covering quiet recording normalization, waveform heights, and multi-language captions at 1080p and 480p.
- **`screenshots/`**: Diagnostic screen captures from automated Playwright test runs.
